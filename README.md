# 🏦 Python Bank Management System

## Overview
This is a simple menu-driven Bank Management System developed using Python. The project was built as part of my
Python learning journey. The original version was written by me, and I later improved it with the help of an AI
assistant improve input validation and add new features. I studied the code line by line and
tested it, debug it , this project helps me lot in debugging my own code , so I can explain how each part works. It demonstrates how core Python concepts can be combined to create
a functional console application.

## Features
- Create multiple bank accounts
- 4-digit PIN protection
- Deposit money
- Withdraw money
- View account details
- View transaction history
- Menu-driven interface
- Input validation for all operations

## Concepts Used
- Python Functions (with `return`)
- Dictionaries
- Lists
- Variables
- User Input
- Conditional Statements (`if`, `elif`, `else`)
- While Loop and For Loop
- Exception Handling (`try`, `except`)
- Basic Program Flow

## How to Run
1. Download or clone this repository.
2. Open the project in any Python IDE or editor.
3. Run the `bank_management_system.py` file.
