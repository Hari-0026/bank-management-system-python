🏦 Python Bank Management System
Overview
This is a simple menu-driven Bank Management System developed using Python. The project was built as part of my
Python learning journey without copying code. It demonstrates how core Python concepts can be combined to create
a functional console application.

Features
- Create a new bank account
- Deposit money
- Withdraw money
- View account details
- Menu-driven interface
- Input validation for basic operations

Concepts Used
- Python Functions
- Dictionaries
- Variables
- User Input
- Conditional Statements ("if", "elif", "else")
- While Loop
- Basic Program Flow

How to Run
1. Download or clone this repository.
2. Open the project in any Python IDE or editor.
3. Run the "bank_management_system.py" file.

Future Improvements
- Support multiple bank accounts
- Transaction history
- File handling for permanent data storage
- Password protection
- Better user interface
